# Contributing

Thanks for your interest!

## Suggested contributions
- Add readiness/liveness probes and resource requests/limits
- Add Git SHA image tagging + registry push (Docker Hub/GHCR)
- Add Kustomize overlays (dev/prod) or a Helm chart
- Add automated tests and a vulnerability scan stage (Trivy)

## How to contribute
1. Fork the repo
2. Create a feature branch
3. Make changes with small commits
4. Open a PR with a clear description
